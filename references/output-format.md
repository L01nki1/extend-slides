# 输出格式规范

所有输出为 Markdown，默认使用**原生写法**，避免依赖额外渲染器。

---

## 格式优先级

按下面顺序选择表达方式，能靠前的就不要用靠后的：

1. 普通段落、列表、**表格**
2. 行内代码 （用于变量名、符号、短表达式）
3. 粗体 `**...**`
4. Mermaid 代码块（仅用于流程图、结构图、关系图）
5. `$...$` / `$$...$$` 数学公式（**最后手段**）

---

## 数学与公式

**默认不使用 LaTeX。** 多数课件公式用 Markdown 原生写法就能表达清楚：

| 场景 | 推荐写法 |
| --- | --- |
| 变量、符号、短表达式 | 行内代码，例如 `D=0`、`beta1`、`Y_it`、`x^2` |
| 变量含义、参数取值 | 表格 |
| 计算步骤 | 有序列表，一步一行 |
| 多变量关系 | 表格或列表 |

只有简单写法**确实无法表达**时才用 `$...$`。典型场景仅限：分式、根式、求和或积分号、上下标组合、矩阵、多行对齐推导。

一旦使用 `$...$`，必须写规范语法，否则渲染会错乱：

- 下标用花括号：`$Y_{it}$`，不要写 `$Y_it$`
- 希腊字母用命令：`$\beta_1$`、`$\varepsilon_i$`，不要写 `$beta_1$`、`$epsilon_i$`
- 不要把公式写进代码块，也不要使用 `\(...\)`、`\[...\]`

---

## 图表

- 流程图、结构图、关系图使用 **Mermaid** 代码块。
- 来自原资料的图片使用相对路径引用，放在 `<课程输出目录>/assets/` 下：

```markdown
![图 3-2 反向传播计算图](./assets/03-12-backprop-graph.png)
```

- 每张图下方必须给出说明：**解释什么** / **看图顺序** / **结论**。

## 原文与讲解

这是本规范最核心的一条：**原文直接呈现，讲解用 `==...==` 包裹。**

### 原文

- **不使用 `>` 引用块。** 课件原文是表格，就还原成 Markdown 表格；是列表，就还原成列表；是段落，就直接写段落。
- 用引用块包裹原文会破坏表格结构，导致整张表无法渲染 —— 这是硬性禁忌。
- 原文可只摘要点，但不得改变原意、不得省略限定条件。
- 除正文外，原文中的备注、批注、提示一律翻译成中文（见「语言处理」）。

### 讲解

- AI 生成的所有讲解内容，统一用 `==...==` 包裹。
- 不加引用块，不写 `AI 补充` 字样，不加任何前缀标签。
- 内容较多时可以逐句或逐段分别包裹，不必强求整段一个标记。

示例：

```markdown
反向传播通过链式法则逐层计算梯度。

==这里课件跳过了链式法则的展开。之所以能逐层回传，是因为每一层的输出都是下一层输入的复合函数，求导时按复合函数求导法则相乘即可。==

==注意：这里的梯度是损失对该层参数的偏导，不是对输入的偏导。两者在第 14 页的练习里会同时出现，容易混淆。==
```

## 来源记录

**正文中不插入任何来源标注**（既不逐段标注，也不用引用块）。来源信息统一集中在每章的「材料来源」表中，粒度到小节：

| 文件名 | 类型 | 对应小节 | 主要内容 |
| --- | --- | --- | --- |
| 03-神经网络.pptx | 课件 | 3.1–3.4 | 反向传播推导与算例 |

## 图片

- 只有**该页含可提取文字**或**本机有 OCR**，且图片确实承担解释作用时，才把图片落地到 `<课程输出目录>/assets/` 并用相对路径引用。
- **无 OCR 时的纯图片页直接跳过**：不要把图片贴进 Markdown 顶替正文。跳过项逐条记入交付报告的存疑条目。
- 不要为了「保留原貌」而批量粘贴课件截图 —— 产物是可读的讲解文档，不是图片集。
- 保留的图片必须配说明：它解释什么、看图顺序、能得出什么结论。

## 语言处理

- **只有原文正文和标题可以保留英语**（照抄原文）。
- **其余一切内容一律中文**：包括讲解、原文中的备注、批注、提示、页眉页脚等，全部翻译成中文。原文的标题需要中英文对照，英文在前，中文在后。即使标题的中英文对照已经在前面术语表中呈现，作为标题的时候仍应该以English（中文）的方式出现。
- 公式、变量名、代码标识符保留原文写法。
- 尽量避免使用“范式”、“哲学”、“锚点”、“建模地图”这类不符合中文日常表达习惯的词语。
- **术语首次出现**：`English Full Name (ABBR, 中文全称)`，例如 `Convolutional Neural Network (CNN, 卷积神经网络)`。缩写在全文中保持首次给出的形式。
- **术语表**（每章固定包含）：

| 英文简称 | 英文全称 | 中文全称 | 含义 | 首次出现 |
| --- | --- | --- | --- | --- |
| CNN | Convolutional Neural Network | 卷积神经网络 | 用卷积核提取局部特征的网络结构 | 3.1 |

若某术语只有全称没有简称，`英文简称` 一列写 `—` 占位。

---

## 术语与符号一致性

- 同一概念在全文中使用同一中文译名与同一英文写法，不要同义混用。
- 增量补充后续章节时，先查 `00-课程总览.md` 的术语总表，沿用已确立的译名。
- **尊重原课件的符号表示**：与通用习惯冲突时保留原表示，如需提示差异，另起一行单独说明，不要直接在正文里替换成通用符号。

---

## 禁止事项

| 禁止 | 原因 |
| --- | --- |
| 用 `>` 引用块包裹原文 | 破坏表格结构，表格无法渲染 |
| 正文中出现来源标注（逐段或引用块形式） | 打断排版；来源统一进「材料来源」表 |
| 给讲解加引用块或 `AI 补充` 字样 | 约定统一用 `==...==` 标记 |
| 输出思维链、模板提示语、检查项、占位说明 | 属内部工作文本，不得出现在产物中 |
| 为简单符号套用 `$...$` | 应优先用行内代码等 Markdown 原生写法 |
| 把公式写进代码块或使用 `\(...\)`、`\[...\]` | 渲染不可靠 |
| 无 OCR 时把纯图片页的图片贴进正文 | 产物会退化成图片集 |
| 只插图不解释 | 图片失去教学作用 |
| 用「必考」「重点考」描述未证实的考点 | 臆造考点 |
| 在正文中呈现教学单位与版权标识 | 非知识点 |
